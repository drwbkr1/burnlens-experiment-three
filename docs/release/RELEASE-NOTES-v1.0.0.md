# BurnLens Experiment Three v1.0.0

This terminal research release demonstrates a complete, replayable neural
change-detection lifecycle and preserves an unfavorable comparative result.

- Lifecycle: **PASS** — fixed architecture, synthetic preflight, three frozen
  trainings, checkpoint selection, safe reload, inference, evaluation,
  packaging, and exact replay completed.
- Comparative: **FAIL** — the three-seed median did not beat the strongest
  constant-class control, and one seed was constant on one test event.
- No post-test tuning, rerun, seed substitution, or protocol change occurred.

The release asset is a public evidence package: software/documentation records,
metrics, hashes, numerical SVGs, and a standalone integrity verifier. It does
not contain benchmark arrays, satellite pixels, labels, model checkpoints,
predictions, probabilities, GeoTIFFs, the imagery-bearing test render, runtime,
private review material, credentials, or secrets.

The known test contains only Ward Creek and Windigo sparse prototype cores.
Events—not pixels—are independent units. Results do not establish dense burn-
scar accuracy, field validity, significance, generalization, superiority,
operational fitness, or wildfire-response utility.
